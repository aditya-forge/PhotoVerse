## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Glassmorphism Sidebar** | Semi-transparent sidebar with blur & box-shadow effects |
| 🍔 **Pure CSS Toggle** | Hamburger menu opens/closes sidebar — _zero JavaScript_ |
| 🖼️ **Full-Screen Background** | Beautiful photography backdrop with `background-size: cover` |
| 🔤 **Poppins Typography** | Clean, modern font via Google Fonts |
| 🎭 **Smooth Hover Effects** | Icon scaling, glow shadows & opacity transitions |
| 📱 **Social Media Links** | Facebook, Twitter, Instagram & YouTube icons |

## 🎓 What I Learned

### 1. Principles of Designing
- **Color Theory** — Understanding the color wheel (primary colors), color meanings, and building palettes (complementary, monochromatic, triadic, analogous, tetradic)
- **Typography** — Choosing font families, weights & styles using Google Fonts
- **Icons** — Integrating icon libraries — Google Material Icons & Font Awesome via CDN

### 2. Web Page Designing
Applied all the above design principles to build **PhotoVerse** — a sidebar navigation interface with:
- CSS-only checkbox hack for toggling the sidebar
- Glassmorphism with `rgba` backgrounds & `box-shadow`
- Smooth transitions using `transition: all 0.3s linear`
- Interactive hover states on menu items, icons & social links
